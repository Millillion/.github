<h3 align="center">Impossibly ambitious AI</h3>

Millillion builds software that used to be out of reach for a small team: compilers, language runtimes and verified-programming tools, built in the open by one engineer directing AI agents. Every project is open source.

### Why "Millillion"?
A **millillion** is the **thousandth "-illion"**. Each -illion adds three more zeros:

> million (1st) = 10<sup>6</sup> · billion (2nd) = 10<sup>9</sup> · trillion (3rd) = 10<sup>12</sup> · … · centillion (100th) = 10<sup>303</sup> · … · **millillion (1000th) = 10<sup>3003</sup>**

The *n*th -illion is 10<sup>3n+3</sup>, so the 1000th is 10<sup>3003</sup>: a 1 followed by 3,003 zeros (*milli-* is Latin for "thousand"). There are only about 10<sup>80</sup> atoms in the observable universe.

Our mark, **ɛ∞ɜ**, is that 3003: an open e and its mirror image, with the zeros turned into infinity.

### Projects
- **[Lasm](https://github.com/Millillion/lasm)**: compile ordinary Lean 4 programs ahead of time to WebAssembly and run them in Node.js. Native acceptance passes on Linux, macOS and Windows (x86-64 and ARM64).
- **[AyeYaiYai](https://github.com/Millillion/ayeyaiyai)**: an AI-first JavaScript → WebAssembly (WASI Preview 2) compiler in Rust, measured against test262.
- **ProofScript**: TypeScript with mathematical verification. Coming later.
