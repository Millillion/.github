<h3 align="center">Impossibly ambitious AI</h3>

Some projects only ever live as ideas. A compiler for an entire language. A runtime that runs anything, anywhere. Software that proves itself correct. You can picture them clearly, but their sheer scale, complexity and the mountain of work involved keep them as dreams.

AI changes that. **Millillion goes after these outrageously ambitious projects, the ones that used to be just dreams, and builds them.** Everything we make is open source.

### Why "Millillion"?
A **millillion** is the **thousandth "-illion"**. Each -illion adds three more zeros:

| | Name | Value |
| --- | --- | --- |
| 1st | million | 10⁶ |
| 2nd | billion | 10⁹ |
| 3rd | trillion | 10¹² |
| 100th | centillion | 10³⁰³ |
| **1000th** | **millillion** | **10³⁰⁰³** |

The *n*th -illion is 10³ⁿ⁺³, so the 1000th is 10³⁰⁰³: a 1 followed by 3,003 zeros (*milli-* is Latin for "thousand"). There are only about 10⁸⁰ atoms in the observable universe.

Our mark, **ɛ∞ɜ**, is that 3003.

### Projects
- **[Lasm](https://github.com/Millillion/lasm)**: compile ordinary Lean 4 programs ahead of time to WebAssembly and run them in Node.js. Native acceptance passes on Linux, macOS and Windows (x86-64 and ARM64).
- **[AyeYaiYai](https://github.com/Millillion/ayeyaiyai)**: an AI-first JavaScript → WebAssembly (WASI Preview 2) compiler in Rust, measured against test262.
- **ProofScript**: TypeScript with mathematical verification. Coming later.
